# model_location_card — default card for Location groups

Standalone (`widget` metadata) card for every semantic Location, generated by rule *Update Model Widgets*.

- **Header**: f7 line icon in a neutral bubble, title, and a "Target 21°" pill (average setpoint) when the room has thermostats.
- **Climate**: average temperature (26 px + unit) and humidity (drop icon) of the room's `Point_Measurement` points — same rule as the Home location cards.
- **Device rows** (rooms without climate): `equipment · state` for up to three equipment with a meaningful state (temperature, switch, opening, alarm), hairline rows.
- **Child rows** (floors, building, Indoor/Outdoor): room, temperature and humidity in aligned tabular columns, chevron; tap opens the room group.
- **Sub line**: "N devices".

## Props
| Prop | Required | Default | Description |
|---|---|---|---|
| `title` | Yes | — | Location name. |
| `icon` | No | `circle` | f7 icon name (or a full icon id). |
| `color` | No | — | CSS colour of the icon (default neutral grey). |
| `tempItems` | No | — | Comma-separated; averaged. |
| `humItems` | No | — | Comma-separated; averaged. |
| `setpointItems` | No | — | Comma-separated; averaged, shown as a "Target" pill. |
| `fallbackItems` | No | — | item|label;… listed when the room has no climate points. |
| `children` | No | — | Floor-level rows: item|title|tempItems|humItems;… (tap opens the group). |
| `sub` | No | — | Small line at the bottom, e.g. "5 devices". |
