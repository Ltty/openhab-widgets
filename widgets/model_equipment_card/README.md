# model_equipment_card — default card for Equipment groups

Standalone (`widget` metadata) card for every semantic Equipment group, generated by rule *Update Model Widgets*
(`managed: true`; set `managed: false` to keep a hand-made card, `heroPin` to fix the hero point).

Layout, top to bottom:
- **Header**: f7 line icon in a 28 px bubble — neutral grey, amber while a light/power switch is on or a door is open/unlocked, red on alarm (`accent` + `activeItem`) — title, and the toggle for switch equipment.
- **Hero**: 26 px value with a separate 12 px unit (long text drops to 18 px), the point label as caption, a 24 h trend line for numeric measurements (tap opens the analyzer). ON/OFF, OPEN/CLOSED and SNAKE_CASE states are humanised; shutters read Open / n % / Closed.
- **Battery chip** only when the battery is low (exceptions-first); nothing when fine.
- **Mini stats**: up to two secondary values side by side under a hairline.
- **Controls**: dimmer slider, or shutter position bar with up / stop / down buttons.

Config values are strings (openHAB drops arrays/objects in metadata config); labels come in through props because
widget expressions only see item states.

## Props
| Prop | Required | Default | Description |
|---|---|---|---|
| `title` | Yes | — | Equipment name. |
| `icon` | No | `circle` | f7 icon name (or a full icon id). |
| `accent` | No | — | light, opening, lock or alarm: tints the icon amber/red while activeItem is active. Empty = neutral. |
| `activeItem` | No | — | Item whose state drives the accent (ON/OPEN, light level > 0, Nuki 3–7). |
| `hero` | No | — | Item shown as the big value. |
| `heroLabel` | No | — | Caption under the value (the point label). |
| `heroKind` | No | — | shutter = show the position as Open / n % / Closed. |
| `secondary1` | No | — | First mini stat. |
| `secondary1Label` | No | — | Caption of the first mini stat. |
| `secondary2` | No | — | Second mini stat. |
| `secondary2Label` | No | — | Caption of the second mini stat. |
| `health` | No | — | LowBattery switch or battery level; a chip shows only when low. |
| `control` | No | — | switch (header toggle), dimmer (slider) or shutter (up/stop/down). Empty = none. |
| `controlItem` | No | — | Item the control sends to. |
| `sub` | No | — | Small line at the bottom, e.g. "8 channels". |
| `analyzerItems` | No | — | Numeric item: 24 h trend under the value, tap opens the analyzer. |
